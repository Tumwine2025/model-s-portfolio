****Twikirize Patience — Model Portfolio

A personal portfolio for Twikirize Patience, showcasing her modeling work, personal style, and interest in fashion and creativity.

🌐 **Live website:** https://tumwine2025.github.io/model-s-portfolio/

About

This project started as a way to bring Patience's photographs and creative interests together in one place.

The design takes inspiration from fashion editorials, with dark backgrounds, warm colors, elegant typography, and a gallery that lets the photographs speak for themselves.

Beyond modeling, the portfolio also explores Patience's interest in fashion and giving existing clothing a new perspective.

## Built With

* **HTML** for the website's structure and content.
* **CSS** for the layout, colours, typography, animations, and responsive design.
* **JavaScript** for scroll reveals, smooth navigation, and other small interactions.
* **Google Fonts** for the Playfair Display and DM Sans typefaces.
* **GitHub Pages** for hosting the website.

## How It Works

**`index.html`**

Contains the content and structure of the portfolio, including the introduction, photo gallery, model profile, personal story, creative section, and contact links.

**`style.css`**

Defines the visual design, from the colours and typography to the gallery arrangement and spacing. It also includes animations, image hover effects, and layouts for desktop, tablet, and mobile screens.

**`script.js`**

Adds scroll-triggered reveals and smooth navigation between sections. It also respects reduced-motion preferences, checks for gallery images that fail to load, and updates the year in the footer automatically.

## Features

* Editorial-style photo gallery with 13 photographs.
* Responsive layouts for different screen sizes.
* Animated introduction and scroll reveals.
* Model profile and measurements section.
* A section dedicated to fashion and clothing reuse.
* Links to Patience's Instagram and contact options.
* Support for visitors who prefer reduced motion.

## Running Locally

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in a browser.

Keep the `images` folder and its filenames unchanged unless you also update the corresponding image paths in the HTML.

## Deployment

The portfolio is hosted on GitHub Pages. Updates pushed to the configured publishing branch can be reflected on the live website.
